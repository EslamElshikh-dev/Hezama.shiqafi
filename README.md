# Hezama.shiqafi

الموقع الرسمي لمؤسسة حزمة شقافي للديكور وتفصيل الخزاين في الرياض.

## Live
https://hezmashoqafi-decoration.vercel.app

## التقنية
- HTML5 دلالي وRTL
- CSS3 متجاوب بالكامل
- Vanilla JavaScript بدون مكتبات خارجية
- Static Site مهيأ للنشر على Vercel

## المميزات
- تصميم متجاوب للجوال والتابلت والكمبيوتر
- دعم الوضع الليلي و`prefers-reduced-motion`
- خدمات النجارة والديكور الخشبي
- خريطة Google مدمجة بتحميل كسول
- مساعد تفاعلي محلي مع 10 أسئلة شائعة
- إرسال الطلب عبر WhatsApp بعد تنظيف النص وترميزه
- SEO metadata + Schema.org + canonical + sitemap + robots
- دعم Accessibility وقفل تمرير الصفحة داخل نافذة المساعد
